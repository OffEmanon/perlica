# Perlica — 个人学习日程与游戏灵感 AI 工作台

面向创作者与开发者的极简双端日志软件（Web / PWA + 本地 SQLite 后端）。

## 核心功能

- **自定义学习板块与每日日程**：自由创建板块（内置「虚幻引擎 UE5」与「数学分析」示例），每个板块支持自定义图标、主题色、长期目标；日志支持 Markdown、代码高亮（C++/Python 等）、LaTeX 数学公式、每日任务清单、学习时长与自评打分。
- **游戏灵感库与 AI 主策划陪跑**：记录碎片闪念、一句话概括、分类、孵化阶段（闪念 → 深化打磨 → 原型验证 → 归档）与优先级；支持 AI **一键扩写玩法与 MVP**、**犀利挑刺找漏洞**、**关联历史灵感跨界碰撞**。
- **高自由度多模型 AI 接入**：兼容 OpenAI、DeepSeek、Google Gemini（原生）、Anthropic Claude（原生）、本地 Ollama 及任意自定义 Base URL；支持一键测试连接与自定义所有 AI 提示词模板。
- **自动复盘汇总 & 个人知识库对话**：支持按日/周/板块一键生成带评分的 AI 复盘报告，以及基于全部历史日志与灵感的流式 AI 参谋对话与智能打标。
- **电脑 + 手机双适配（PWA）**：响应式界面 + 手机底部导航 + 局域网扫码直连，支持添加到手机主屏幕。

## 快速启动

```bash
# 生产一体化模式（推荐，电脑与手机同端口访问 http://localhost:3000）
npm run build
set NODE_ENV=production&& npm run start

# 或者直接双击 Windows 启动脚本：
start-perlica.bat

# 开发热更新模式
npm run dev
```
